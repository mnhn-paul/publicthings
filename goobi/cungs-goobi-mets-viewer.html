METS Event Viewer

Extracts event notes from one or more METS/MODS files, shows the pages they are on, and exports table, Darwin Core Event Core or Excel.

Options (CORS proxy, record IDs)

A bare record ID such as MNHNL2024-6-01 is expanded to https://face.mnhn.gov.lu/viewer/sourcefile?id=…. Loading a URL that is already shown replaces its block.

Data curation & export

Names and person IDs below are used for recordedBy / recordedByID and identifiedBy / identifiedByID on the occurrences; the ID fields contain the person ID only. For every event, sampleSizeValue / sampleSizeUnit are calculated from the event time interval, in minutes, and continent / country are filled in for Luxembourg. Only the actual observation events (with date and time) are exported; each event ID combines the general location and visit date (e.g. Haardt-2007-05-24) with the METS section identifier. Communes assigned in the Localities tab are exported as municipality, and the mapping in the Taxon names tab adds standardized names, higher taxonomy and taxon IDs to the occurrences.

Assign coordinates in decimal degrees (WGS84), a coordinate uncertainty in meters and the commune to each locality; they are exported as decimalLatitude / decimalLongitude / coordinateUncertaintyInMeters / municipality on the events of that locality. All records are in Luxembourg, so country = Luxembourg, countryCode = LU and continent = Europe are filled in automatically. Entries are kept in your browser; you can download the mapping as CSV to back it up or edit it externally, then import it back.

Map each taxon name as written in the documents to a standard (accepted) scientific name, its higher taxonomy and a taxon ID such as a Catalogue of Life (COL) ID. In the exports the standard name becomes scientificName, the original name is kept as verbatimIdentification, and kingdom / phylum / class / order / family / taxonID are added to the occurrences. Unmapped names are exported unchanged. CSV exports from the GBIF/CoL species match are recognised directly: verbatimScientificName is used as the name in the document, scientificName as the standard name, and acceptedUsageKey / usageKey / key as the taxon ID when present. Entries are kept in your browser; you can download the mapping as CSV to back it up or edit it externally, then import it back.

Overview of the loaded documents: how many structure elements of each type they contain, how many pages are still unassigned, and how far the curation of events, localities and taxon names has progressed. The numbers update automatically whenever records are loaded or a mapping is imported.

Every observation event with a date is plotted as a dot on a time axis — one lane per site (locality), dots coloured by record; the bars on top show how many visits fall into each period. Click a dot to open the event's first page in the image viewer.
