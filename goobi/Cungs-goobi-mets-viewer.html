METS Event Viewer

Extracts event notes from one or more METS/MODS files, shows the pages they are on, and exports table, Darwin Core Event Core or Excel.

Options (CORS proxy, record IDs)

A bare record ID such as MNHNL2024-6-01 is expanded to https://face.mnhn.gov.lu/viewer/sourcefile?id=…. Loading a URL that is already shown replaces its block.
